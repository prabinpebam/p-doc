# FL-002 Review with comments and suggestions
User goal: propose and settle changes without losing the original · Features: F-027, F-028, F-029 · Status: draft

## Steps

| # | Screen | User action | System response | Evidence |
|---|---|---|---|---|
| 1 | S-001 | Switch to Suggesting (Ctrl+Alt+Shift+X) | Mode menu shows Suggesting; a badge appears at the cursor | [doc SRC-001] [obs EV-001] |
| 2 | S-001 | Type and delete | Edits shown as suggestions with a card in the margin | [doc SRC-003] |
| 3 | S-001 | Select text, Ctrl+Alt+M, write a comment | Comment card anchored to the selection | [doc SRC-001] [doc SRC-004] |
| 4 | S-001 | Tools > Review suggested edits | Panel to step through suggestions with accept and reject, or accept/reject all | [obs EV-003] [doc SRC-003] |
| 5 | S-003 | Resolve the comment | Card leaves the margin; kept as resolved | [doc SRC-004] |
