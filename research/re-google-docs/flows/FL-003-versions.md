# FL-003 Go back to an earlier version
User goal: see what changed and restore or name a version · Features: F-031 · Status: draft

## Steps

| # | Screen | User action | System response | Evidence |
|---|---|---|---|---|
| 1 | S-001 | Click the last-edit indicator or File > Version history > See version history | Version history opens with a list at the right | [doc SRC-002] [obs EV-003] |
| 2 | S-004 | Select a version | That version shows with changes highlighted | [doc SRC-002] |
| 3 | S-004 | More > Name this version | Name saved; named versions can be filtered | [doc SRC-002] |
| 4 | S-004 | Restore this version > Restore | It becomes current; history kept | [doc SRC-002] |
| 5 | S-004 | Back | Returns to the editor | [doc SRC-002] |
