# Glossary

| Term | Definition | Evidence |
|---|---|---|
| Pageless | Format with no page breaks; headers, footers, page numbers and columns hidden | [doc SRC-005] |
| Text width | Width of text in pageless: narrow, medium, wide, full | [doc SRC-005] |
| Suggesting | Mode where edits become suggestions others accept or reject | [doc SRC-003] |
| Named version | A version given a name in version history; up to 40 per document | [doc SRC-002] |
| Document tabs | Separate pages of content inside one document, listed in the left sidebar | [obs EV-001] |
| Outline | List of headings in the sidebar used to jump through the document | [doc SRC-008] |
| Smart chip | Inline element for a person, file, date or place | [obs EV-003] |
| Building block | Ready-made inserted structure such as a meeting notes template | [obs EV-003] |
