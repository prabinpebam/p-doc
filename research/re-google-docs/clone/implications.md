# Implications for the clone

## Copy

| Area | Item | Why | Refs |
|---|---|---|---|
| Saving | Autosave with a save state beside the title | No lost work, no Save step | R-001, F-036 |
| Review | Editing / Suggesting / Viewing as one mode switch | Review without a separate tool | R-005, F-029 |
| Navigation | Outline built from headings | Zero setup | R-002, F-022 |
| Layout | Pages / pageless toggle | Draft wide, print true | R-003, F-016 |
| Toolbar | Shortcut in every button name | Teaches keys | R-010 |

## Avoid

| Area | Item | Why | Refs |
|---|---|---|---|
| Storage | Cloud-only documents | Writer does not own the file | B-001 |
| TOC | Manual refresh | Stale contents | B-002, R-009 |

## Improve

| Area | Item | How | Refs |
|---|---|---|---|
| TOC | Live table of contents | Rebuild from headings on every change | R-009 |
| Versions | Versions as git commits | History survives outside the app; named versions are tags | R-006, R-007 |
