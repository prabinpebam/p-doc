# Charter: Google Docs
Date: 2026-10-28

| Item | Value |
|---|---|
| Goal | Learn how Google Docs works (features, screens, interactions, rules) so that P-Doc, a desktop hybrid of Google Docs and Microsoft Word, can take its best parts. Feeds `docs/product/spec.md`. |
| Requested by | Owner (prabinpebam): "To document features, capabilities, UX, UI and every detail interactions to prepare a complete spec." |
| Scope | Document editor: menus, toolbar, editing and formatting, styles, pages and pageless, page setup, headers and footers, footnotes, outline, table of contents, find and replace, comments, suggesting, version history, offline, keyboard shortcuts. |
| Out of scope | Real-time co-editing internals, Drive sharing and permissions, add-ons, Gemini, Sheets, Slides, mobile apps, admin console. |
| Clone target market | One writer on a desktop computer who keeps documents in their own GitHub repositories (private by default, public to publish) and works offline. |
| Priorities | P1 writing and formatting loop; P2 page layout; P3 versions; P4 comments and suggestions; P5 settings. |
| Mode | Unattended |
| Environment level | L4 observe-only on public pages (a public view-only document) plus public help-centre documentation. No sign-in. |
| Write authorization | None. No account, no writes; menus were opened and closed (A1) only. |
| KB language | English |
| Terms of service | https://policies.google.com/terms: the study observes public pages and help articles only, copies no code, assets or long text, and makes no automated writes. |
