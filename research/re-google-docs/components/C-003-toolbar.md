# C-003 Formatting toolbar
Product name: `#docs-toolbar` · Used in: S-001 · Status: draft

## Anatomy

One rounded pill bar of icon buttons and pickers grouped by separators: history, print and tools; zoom; style; font; size stepper; character format; insert; paragraph; lists; indent; clear; at the right the mode switch and collapse. Every button carries its shortcut in its accessible name, for example "Bold (Ctrl+B)". [obs EV-002]
