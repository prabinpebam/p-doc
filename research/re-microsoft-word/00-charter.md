# Charter: Microsoft Word
Date: 2026-10-28

| Item | Value |
|---|---|
| Goal | Learn how Microsoft Word works (features, screens, interactions, rules) so that P-Doc, a desktop hybrid of Google Docs and Microsoft Word, can take its best parts. Feeds `docs/product/spec.md`. |
| Requested by | Owner (prabinpebam): "To document features, capabilities, UX, UI and every detail interactions to prepare a complete spec." |
| Scope | Word for Windows and Word for the web document editing: ribbon, styles, navigation pane, sections and section breaks, headers and footers, page setup, columns, table of contents, find and replace, comments, track changes, compare, AutoSave and version history, focus and immersive reading, keyboard shortcuts. |
| Out of scope | Mail merge, macros and VBA, SharePoint and OneDrive permissions, Copilot, real-time co-authoring internals, admin policy. |
| Clone target market | One writer on a desktop computer who keeps documents in their own GitHub repositories (private by default, public to publish) and works offline. |
| Priorities | P1 writing and formatting loop; P2 page layout; P3 versions; P4 comments and tracked changes; P5 settings. |
| Mode | Unattended |
| Environment level | L4: public help-centre documentation and the public product page. No sign-in; Word for the web needs a Microsoft account, so live observation is listed under Needs human. |
| Write authorization | None. |
| KB language | English |
| Terms of service | https://www.microsoft.com/servicesagreement: the study reads public documentation only, copies no code, assets or long text, and makes no automated writes. |
