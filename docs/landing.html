P-Doc · desktop word processor

P-Doc

Google Docs' ease and Word's structure, in files you own: every document is versioned in your own private and public GitHub repositories and works fully offline.

TL;DR

Research is done (Google Docs observed with Stagehand, Word from its documentation). The spec and Definitions of Done are written. Stages 1, Write offline, 2, Pages and print, 3, Versions, 4, Review, and 5, GitHub and first run, are built and pass every DoD row, as is 6, Import and export (28 end-to-end journeys, 126 unit tests, performance within budget). Pages on screen match the PDF page for page, which confirms the riskiest assumption (A1). Every document has a version history (compare, name, restore, copy) and can be reviewed: suggest changes, comment, accept or reject. Connect GitHub sets up a private and a public repository and keeps them in sync; a document reaches the public one only after you confirm. Word, Markdown, web pages and text come in and go out, and the pdoc command line works on the same library. This page shows where each stage stands.
