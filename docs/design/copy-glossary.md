# P-Doc copy glossary

Words P-Doc uses, and the words it doesn't. Sentence case everywhere; no exclamation marks.

| Term | Use for | Don't say |
|---|---|---|
| document | A P-Doc file the writer works on | doc, file (except in import/export), note |
| library | All the writer's documents in P-Doc | workspace, vault, drive |
| Private | The private repository and its documents | personal, secret, hidden |
| Public | The public repository and its documents | shared, published |
| version | A saved state in history (a Git commit) | revision, commit, snapshot |
| named version | A version with a name (a Git tag) | tag, milestone, checkpoint |
| version history | The list of versions | revisions, log |
| restore | Make an earlier version current | revert, roll back |
| save state | The words beside the title that say whether changes are saved | status |
| Saved to this computer | Written to disk, not yet on GitHub | Saved locally |
| Saved · synced | Written and pushed | Up to date |
| sync | Exchange versions with GitHub | push, pull, upload |
| Offline | No network; everything still works | disconnected, error |
| suggestion | A proposed insertion or deletion in Suggesting | tracked change, revision, redline |
| comment | A note on a piece of text; has replies | annotation, note |
| resolve | Close a comment, keeping it | archive, done |
| Editing / Suggesting / Viewing | The three modes | Edit mode, Review mode, Read-only |
| markup | How suggestions show: Simple, All, No markup, Original | display for review |
| Pages / Pageless | The two layouts | print layout, web layout |
| page setup | Paper, orientation, margins, page colour | page settings, layout options |
| header / footer | Repeating text at the top/bottom of pages | running head |
| outline | The headings list in the left panel | navigation pane, TOC |
| table of contents | The block inside the document listing headings | TOC (in UI) |
| Bin | Deleted documents, recoverable | Trash, Recycle bin |
| Connect GitHub | Start sign-in and repository setup | Log in, Link account |
| sign in / sign out | GitHub account in Git's helper | log in, log out |
| command search | Alt+/ popover to run any command | Tell me, palette |
| image | A picture placed in a document (PNG, JPEG, GIF, WebP, SVG, BMP) | picture, photo, graphic |
| alt text | The description of an image for people who can't see it | alternative text, caption |
| crop | Hide the edges of an image without changing the file | trim, clip |
| In line with text / Wrap left / Wrap right | Where an image sits: in the line, or with text flowing round it | float, square, tight |
| Image missing | An image whose file isn't in the repository | broken image |
| indent (Left, Right, First line, Hanging) | How far a paragraph sits in from the margins; Left is where the body lines start | margin (for a paragraph), outdent |
| tab stop | A position a tab moves to, with alignment Left, Centre, Right or Decimal | tab position, tabulator |
| leader | Dots, dashes or a line filling the space before a tab stop | fill, tab fill |
| ruler | The scale above the page with the margins, indents and tab stops | guide, measure bar |
| non-printing characters | ¶, ·, → and ↵ shown on screen and never printed | formatting marks, hidden characters, pilcrows |
| Sort | Put paragraphs, list items or table rows in order, A to Z or Z to A | order, arrange |
